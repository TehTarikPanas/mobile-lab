## About the Lab Exercise
Recipe App is a mobile application developed using Flutter that helps users explore various food and beverages recipes.

Users can browse recipe by searching dishes name and view detailed recipe information including descriptions, ingredients, and serving sizes. The serving slider dynamically adjusts ingredient quantities based on the selected number of servings.

---

## Tech Stack
- **Framework** – Flutter
- **Language** – Dart

---

## Quick Start
To get a local copy up and running, follow these simple steps:

### Prerequisites
- Before running the project, make sure you have:
- Flutter SDK installed
- Dart SDK installed
- Android Studio & VS Code
- Chrome (for Flutter Web testing)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/recipe-app.git
   ```
2. Navigate to the project folder:
   ```bash
   cd recipe-app
   ```
3. Install Dependencies
   ```bash
   flutter pub get
   ```
4. Run the Application
For Chrome:
   ```bash
   flutter run -d chrome
   ```
   
---

## Usage
- **Search Recipes**
- Enter a recipe name in the search bar.
- Matching recipes will be displayed automatically.

- **View Recipes**
- Tap any recipe card.
- The Recipe Detail page will open.

- **Adjust Servings**
- Use the servings slider.
- Ingredient quantities will automatically update based on the selected serving size.
